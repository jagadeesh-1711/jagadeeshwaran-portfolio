Test automation

Playwright + Pytest Test Automation

An automated test suite for a web-based login application, built to check the paths users take and the ones they stumble into, from first page load to repeated logins.

Python holds the test logic, Playwright drives the browser like a real user, and Pytest runs the tests and reports each result.

Reusable, readable test logic and systematic debugging kept the suite reliable and improved my code quality.

Key features

  • Valid and invalid login scenarios
